Setup Guide: Solana Memecoin Sniper Bot

From Zero to Running — Complete Beginner Guide

What We'll Do

  1. Install VirtualBox (run Ubuntu inside your computer)
  2. Install Ubuntu 22.04 (the Linux operating system)
  3. Deploy the bot scripts and configuration
  4. Test everything in safe DRY_RUN mode

Before You Start, Make Sure You Have:

  • A computer with at least 8GB RAM (16GB recommended)
  • At least 50GB free disk space
  • A working internet connection
  • About 1 hour of free time
  • No prior Linux experience needed!
01
Install VirtualBox

VirtualBox lets you run Ubuntu inside your current operating system (Windows or Mac) without replacing anything. Think of it as a "computer inside your computer."

Watch: How to Install Ubuntu in VirtualBox (2026 Updated) — TechOpt

1.1 Download VirtualBox

  1. Open your web browser
  2. Go to: https://www.virtualbox.org/wiki/Downloads
  3. Click the download for your system:
    Windows: Click "Windows hosts"
    Mac: Click "macOS / Intel hosts" (or Apple Silicon for newer Macs)
  4. Wait for the download to finish
📸 You should see this page — click the link for your operating systemvirtualbox.org/wiki/Downloads

1.2 Install on Windows

  1. Double-click the downloaded file (e.g., VirtualBox-7.x.x-Win.exe)
  2. Click Next on the welcome screen
  3. Click Next again (keep default settings)
  4. Click Next (network warning is normal, click Yes)
  5. Click Install
  6. If asked "allow this app to make changes?" click Yes
  7. Click Finish when done

1.3 Install on Mac

  1. Double-click the downloaded .dmg file
  2. Double-click the VirtualBox.pkg icon
  3. Follow prompts: click Continue and Install
  4. If asked, go to System Preferences → Security & Privacy → click Allow
  5. Restart your Mac if prompted

1.4 Verify It Worked

Search for "VirtualBox" in your Start Menu (Windows) or Applications (Mac) and open it.

📸 The VirtualBox Manager — an empty list with toolbar buttons at the topThis is what success looks like!
If you see the VirtualBox Manager window, you're done with Step 1!
02
Install Ubuntu 22.04
Watch: How to Install Ubuntu Linux on VirtualBox in 2026 — Inno Techy

2.1 Download Ubuntu

  1. Go to: https://releases.ubuntu.com/22.04/
  2. Click "64-bit PC (AMD64) desktop image"
  3. Wait for download to complete (about 4.5GB, may take 10-30 minutes)

2.2 Create a Virtual Machine

  1. Open VirtualBox
  2. Click the New button (blue star icon)
  3. Set Name: Ubuntu Bot
  4. Set ISO Image: Click dropdown → Other → browse to your downloaded .iso file
  5. Set Type: Linux, Version: Ubuntu (64-bit)
  6. Check "Skip Unattended Installation"
  7. Click Next
📸 New Virtual Machine dialog — fill in the name, select your ISO fileMake sure "Skip Unattended Installation" is checked

2.3 Allocate Resources

  1. Memory: Set to 4096 MB (4GB). If you have 16GB+ RAM, use 8192 MB
  2. Processors: Set to 2 CPUs
  3. Click Next
More RAM = smoother experience. If your computer has 16GB, give the VM 8GB.

2.4 Create Virtual Hard Disk

  1. Select "Create a Virtual Hard Disk Now"
  2. Set size to 40 GB
  3. Click Next, then Finish

2.5 Install Ubuntu

  1. Select Ubuntu Bot in the list, click the green Start arrow
  2. Wait for Ubuntu to load (1-2 minutes)
  3. Select English, click "Install Ubuntu"
  4. Choose keyboard layout, click Continue
  5. Select "Normal installation", check "Download updates", click Continue
  6. Select "Erase disk and install Ubuntu", click Install Now
Don't worry about "Erase disk"! This only erases the virtual disk inside VirtualBox, NOT your real computer. Your files are completely safe.
  1. Select your timezone, click Continue
  2. Create your account: pick a name, username, and password you'll remember
  3. Select "Log in automatically" for convenience
  4. Click Continue and wait 10-20 minutes for installation
  5. Click "Restart Now", press Enter when prompted
Ubuntu is installed! You should see the desktop after restart.

2.6 Install Guest Additions (Recommended)

  1. In VirtualBox menu: Devices → Insert Guest Additions CD image
  2. Click Run if Ubuntu asks, enter your password
  3. Wait for it to finish, then restart Ubuntu
03
Deploy the Scripts

3.1 Open the Terminal

Press Ctrl + Alt + T to open the Terminal.

To paste into the terminal, use Ctrl + Shift + V (not just Ctrl+V).

3.2 Update Ubuntu

sudo apt update sudo apt upgrade -y

Enter your password when asked. You won't see it typing — that's a security feature.

3.3 Install Python 3 and Tools

sudo apt install python3 python3-pip python3-venv git unzip -y

Verify:

python3 --version
You should see Python 3.10.x or higher.
Watch: How to Install Python 3 on Ubuntu — DevSecOps Club

3.4 Get the Bot Code

Choose ONE of these three methods. Method A is recommended for beginners:

A: Git Clone
B: Zip Download
C: Manual
Recommended

Best for: Anyone comfortable typing one command. Easiest to update later.

# Clone the repository git clone https://github.com/YOUR_REPO/sniper-bot.git ~/sniper-bot cd ~/sniper-bot

That's it. All files are now on your machine.

Replace the URL above with the actual repository link provided in your course materials.
Easy

Best for: If you downloaded the zip file from Udemy's course resources.

  1. Download the sniper-bot.zip from the Udemy course resources section
  2. If downloaded on your host computer, drag and drop the zip into your Ubuntu VM
  3. In terminal, run:
# Navigate to where the zip was downloaded cd ~/Downloads # Unzip it unzip sniper-bot.zip -d ~/sniper-bot # Go into the folder cd ~/sniper-bot
If drag-and-drop doesn't work, install Guest Additions first (Step 2.6) or use a USB drive.
Learn Every Line

Create each file with nano:

# Create token_scanner.py nano token_scanner.py # Paste the full token_scanner.py code, then: Ctrl+O, Enter, Ctrl+X # Create bot.py nano bot.py # Paste the full bot.py code, then: Ctrl+O, Enter, Ctrl+X

The code files are shown line-by-line in the course video modules.

3.5 Set Up Virtual Environment & Dependencies

# Create virtual environment python3 -m venv venv # Activate it (you'll see "(venv)" appear in your prompt) source venv/bin/activate # Install all dependencies from requirements.txt pip install -r requirements.txt
The requirements.txt file is included with the code. It installs everything the bot needs in one command.

3.6 Configure Your .env File

Create your configuration file:

nano .env

Paste this exact content (replace YOUR_KEY values with your own):

WALLET_PRIVATE_KEY=YOUR_KEY DRY_RUN=true TOKEN_MODE=scan STOP_LOSS_MULT=0.82 POLL_INTERVAL_SEC=8 MIN_PLAY_AMOUNT=1.00 MAX_CONSEC_LOSSES=2 LOSS_PAUSE_SEC=300 STARTING_AMOUNT_USDC=2 #SOLANA_RPC_URL=https://api.mainnet-beta.solana.com SOLANA_RPC_URL=https://solana-mainnet.g.alchemy.com/v2/YOUR_KEY SLIPPAGE_BPS=150

Save: Ctrl+O, Enter, Ctrl+X.

Notice the commented-out line (#SOLANA_RPC_URL). The default Solana RPC is slow and rate-limited. We use Alchemy instead. Get a free API key at alchemy.com and replace YOUR_KEY with your actual key.
Important: Keep DRY_RUN=true for testing! Only change to false after completing the full 24-hour test and the Going Live module.

What each setting means:

SettingWhat It Does
WALLET_PRIVATE_KEYYour Solana wallet's private key (base58 format)
DRY_RUNtrue = simulate trades, false = real money
TOKEN_MODEscan = auto-find tokens via WebSocket
STOP_LOSS_MULT0.82 = sell if price drops 18% from entry
POLL_INTERVAL_SECCheck price every 8 seconds
MIN_PLAY_AMOUNT$1 floor (resets bankroll if it drops below this)
MAX_CONSEC_LOSSESPause after 2 straight losses
LOSS_PAUSE_SECWait 300s (5 min) after consecutive losses
STARTING_AMOUNT_USDC$2 per trade (start small!)
SOLANA_RPC_URLYour Alchemy/Helius RPC endpoint
SLIPPAGE_BPS150 = 1.5% slippage tolerance on swaps

3.7 Verify Your Deployment

ls -ltr

You should see this file structure:

requirements.txt ← dependency list README.md ← documentation token_scanner.py ← WebSocket listener bot.py ← main trading bot .env ← your config (private!) venv/ ← virtual environment docs/ ← additional documentation

After running the bot, these files will be auto-generated:

bot.log ← activity log journal.json ← trade history (JSON) trade_log.csv ← trade history (CSV) __pycache__/ ← Python cache (ignore)
File structure matches? You're ready to test!
04
Test the Bot

4.1 Confirm DRY_RUN is Enabled

cat .env | grep DRY_RUN
You MUST see DRY_RUN=true. If it says false, run nano .env and fix it!

4.2 Test the Token Scanner

# Make sure venv is active source venv/bin/activate # Run the scanner python3 token_scanner.py

What you'll see:

📡 WebSocket Token Scanner — listening for new pump.fun launches... Will wait up to 5 minutes for a qualifying token. 🚀 NEW TOKEN: EXAMPLE (Example Token) Mint: AbCdEf... Initial buy: 2.50 SOL ⏳ Waiting 25s for pair data...

Press Ctrl + C to stop.

OutputMeaning
"Would buy: TOKEN"✅ Scanner found a qualifying token
"SKIP TOKEN: low liquidity"✅ Working, filtering correctly
"No qualifying token found"✅ Normal! Good tokens are rare
"Connection refused"❌ Check internet connection
"ModuleNotFoundError"❌ Activate venv and run pip install -r requirements.txt

4.3 Test the Full Bot

python3 bot.py

In DRY_RUN mode: detects, scores, and filters tokens (real data), but skips actual transactions. Everything is logged.

4.4 Check the Logs

# See last 30 lines of activity tail -30 bot.log # See trade journal cat journal.json # See CSV trade log cat trade_log.csv

4.5 Run a 24-Hour Test

# Install tmux (keeps bot running in background) sudo apt install tmux -y # Start a named session tmux new -s bot # Inside tmux: cd ~/sniper-bot source venv/bin/activate python3 bot.py # Detach (bot keeps running): press Ctrl+B, then D # Come back later: tmux attach -s bot
Let the bot run for at least 24 hours. Check bot.log periodically. You want to see it detecting tokens, scoring them, and filtering most out.

4.6 Success Checklist

After your 24-hour DRY_RUN test:

  • Bot stayed running without crashes
  • bot.log shows tokens being detected (🚀 lines)
  • bot.log shows tokens being scored and filtered
  • journal.json exists and contains data
  • trade_log.csv has entries
  • No error messages repeating continuously
  • WebSocket reconnected if it disconnected
All boxes checked? Congratulations! Your bot is validated. Proceed to Module 12 (Tuning & Going Live) when ready. 🎉
