Setup Guide

Jupiter Compounding Bot

Automate your compounding strategy on Jupiter.ag (Solana) — deploy, configure, and run in about 5 minutes.
Use → / ← or the buttons below to navigate
Overview

The Strategy

Buy token with USDC → wait for 2x → sell → save 40% → reinvest 60% → repeat

Every winning cycle locks in profit and compounds the rest forward into the next trade — automatically.

Follow the Steps in Order

  • Each setup step depends on the one before it — don't skip ahead
  • Total setup time: about 5 minutes
  • Always test in dry-run mode before going live
STEP 1 OF 6

Install Python Dependencies

As the root user

sudo apt update sudo apt upgrade -y # Install Python 3 and tools sudo apt install python3 python3-pip python3-venv git unzip -y # Verify it installed correctly python3 --version

As the application user

This is the user account that will actually run the bot day-to-day.

pip install -r requirements.txt
Run the first block as root just once. Everything after that should run as the regular user who will operate the bot.
STEP 2 OF 6

Configure Your .env

Copy the scripts to your bot directory

cp bot.py /home/vboxuser/trading_app/ cp token_scanner.py /home/vboxuser/trading_app/

Create your config file

cp .env.example .env nano .env # or open in any editor
Fill in WALLET_PRIVATE_KEY — export it from Phantom: Settings → Security → Export Private Key. Never share this file with anyone.
STEP 2 OF 6

What Goes in .env

WALLET_PRIVATE_KEY=YOUR_PK_KEY DRY_RUN=true TOKEN_MODE=scan STOP_LOSS_MULT=0.82 POLL_INTERVAL_SEC=8 MIN_PLAY_AMOUNT=1.00 MAX_CONSEC_LOSSES=2 LOSS_PAUSE_SEC=300 STARTING_AMOUNT_USDC=2 #SOLANA_RPC_URL=https://api.mainnet-beta.solana.com SOLANA_RPC_URL=https://solana-mainnet.g.alchemy.com/v2/YOUR_API_KEY SLIPPAGE_BPS=150
SettingWhat It Does
WALLET_PRIVATE_KEYYour Solana wallet's private key
DRY_RUNtrue = simulate only, false = real money
STOP_LOSS_MULT0.82 = sell if price drops 18% from entry
STARTING_AMOUNT_USDCHow much USDC each cycle starts with
Leave DRY_RUN=true until you've fully tested the bot.
STEP 3 OF 6 · RECOMMENDED

Get a Free RPC Endpoint

The public Solana RPC is rate-limited and unreliable for a bot that needs to check prices frequently.

  1. Go to https://www.helius.dev and sign up (the free tier is plenty)
  2. Copy the RPC URL Helius gives you
  3. Paste it into SOLANA_RPC_URL in your .env file
A dedicated RPC endpoint means fewer dropped connections and faster price checks — worth the two minutes it takes to sign up.
STEP 4 OF 6 · OPTIONAL

Get a Birdeye API Key

Birdeye gives more reliable price feeds than Jupiter's fallback pricing.

  1. Go to https://birdeye.so
  2. Navigate to Developer → API Keys
  3. Generate a free key
  4. Paste it into BIRDEYE_API_KEY in your .env file
This step is optional but recommended if you want more accurate 2x-target detection.
STEP 5 OF 6

Run in Dry-Run Mode First

python bot.py

With DRY_RUN=true, you'll see the full projection table and simulated cycles — no real transactions are made.

Use this stage to confirm your settings, RPC connection, and compounding math all look right before any real funds are involved.
STEP 6 OF 6

Go Live

Once you're happy with the dry run results, switch the bot to real trading:

# In .env, change: DRY_RUN=false

Then run the bot again:

python bot.py
Keep the terminal open. If it closes, just restart — the bot picks up exactly where it left off using journal.json.
Reference

How It Works

Cycle 1: Buy $7.77 USDC of SOL → Monitor price every 10 seconds → Price hits 2x entry price → Sell all SOL back to USDC → Receive ~$15.54 USDC → Save $6.22 (40%) → Reinvest $9.32 (60%) → next cycle Cycle 2: Buy $9.32 USDC of SOL → ... repeat

This matches the spreadsheet exactly: each win compounds 60% forward, and 40% is locked in as saved profit.

Reference

Realistic Expectations

The bot executes the compounding math correctly, but the 2x target is not guaranteed:

  • SOL price moves — hitting 2x may take hours, days, or never happen
  • If price drops significantly, you'll sell at a loss (or hold until it recovers)
  • Enable STOP_LOSS_MULT=0.8 to auto-sell if price drops 20%
  • Gas and slippage cost ~0.5% per swap — this adds up over 30 cycles
Start small. Test with $7.77 as shown in the spreadsheet before scaling up.

# Volatile memecoins (higher chance of 2x, higher chance of 0) BONK = DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263 WIF = EKpQGSJtjMFqKZ9KQanSqYXRcF8fBopzLHYxdM65zcjm JUP = JUPyiwrYJFskUPiHa7hkeR8VUtAeFoSYbKedZNsDvCN
More volatile tokens can hit 2x faster — but they're also far more likely to go to zero. Choose deliberately.
Reference

Emergency Stop

  1. Press Ctrl+C at any time — your state is saved in journal.json
  2. The bot resumes right where it left off on next start
  3. To exit an open position manually: go to jup.ag, connect your wallet, and swap back to USDC
  4. Then delete journal.json and restart
Deleting journal.json resets the bot's memory of your cycle — only do this after manually closing any open position.
